Features

Everything you need
to work with Aerospike

Connection Manager
Save multiple Aerospike connection profiles with TLS support. Test latency before connecting. Switch between dev, staging, and prod in one click.
Namespace & Set Browser
Navigate your entire namespace hierarchy in a collapsible tree. Scan sets with paginated record views, live record counts, and memory stats.
Record Inspector
View, create, update, and delete Aerospike records. Edit individual bins with type-aware inputs. Set TTLs and track generation counts directly from the UI.
AQL Editor
Full-featured AQL query editor with persistent history, token-level syntax highlighting, and a built-in cheat sheet for every statement type.
Visual Query Builder
Build queries with point-and-click filter rows — eq, range, and contains operations. No AQL required. Results stream into a sortable, resizable table.
Cluster Dashboard
Real-time cluster health streamed via WebSocket. Per-node stats, memory usage, active connections, and latency — all visible at a glance.
How it works

Zero to querying
in three steps

01
Connect
Add your Aerospike host, port, and optional credentials. Click "Test" to measure latency and verify connectivity. Save as a named profile.
02
Browse
Navigate the namespace tree in the sidebar. Select a set to scan its records — paginated, filterable, and fully editable without writing a line of code.
03
Query
Write AQL directly or use the visual query builder. Run queries, inspect results in table or JSON mode, and export data without leaving the app.

Query history with replay
Every query is saved automatically. Browse, search, and re-run past queries from the history panel. Persists across app restarts.
Full DDL support
Run CREATE INDEX, DROP INDEX, INSERT, DELETE — all AQL statement types are supported, not just SELECT.
Built-in syntax reference
The cheat sheet tab covers the full AQL syntax without leaving the app. No browser tab, no docs search, no distractions.
Table or JSON results
Switch between a structured table view and raw JSON mode for deep record inspection. Copy individual cell values in one click.
